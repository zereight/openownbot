### Changed

- The desktop app is built as ROBot: the app is `ROBot.app` and `ROBot.exe`, the release files are `ROBot-<version>-…`, and the macOS app id is `app.robot.desktop`. An installed OpenOwnBot does not update to ROBot; install ROBot from the release page. Hosted servers install into `/opt/ROBot`.
- The mobile app shows the name ROBot. Its bundle ids do not change.
