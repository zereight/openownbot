### Added

- Edit an agent: a dice button next to the name picks a random name that no other agent on the server has. A button next to the title lists the titles that other agents have, so you can pick one.
- Workflow steps show their number, the same number as the canvas on the desktop.
- Server settings: owners and admins can set how often agents on the server review their chats for lasting memories, as on the desktop.
- Chats show how full the context window is once it is half full, as on the desktop. Tap it to see the tokens, what fills them and when the chat compacts. The server must run this version.
- A task that waits for your approval or a browser takeover appears under "Actions needed" in the task list.

### Changed

- Deleted channels are now called archived channels, as on the desktop. Archiving a channel keeps its history for preview, and you can restore it.

### Fixed

- A browser takeover card that the server no longer waits on (for example after Stop) now disappears when you answer it, and no longer shows an error.

### Removed

- Remove the Marketplace from the app. Add agents, skills and apps from the desktop app. Your installed agents, skills and apps keep working, and you can still turn a skill on or off for an agent.
